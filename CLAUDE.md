## Что это
Telegram-бот для учёта питания. Пользователь пишет еду свободным текстом, LLM раскладывает её на продукты, граммы, калории и БЖУ, бот сохраняет запись.

## Стек
- Python, pyTelegramBotAPI (telebot), SQLite (`calories.db`), python-dotenv
- LLM: Anthropic API (`claude_client.py`, модель Claude Haiku 4.5), ключ в `.env` (`ANTHROPIC_API_KEY`), токен бота тоже в `.env`
- Windows, виртуальное окружение `.venv`, запуск через `run_bot.bat`

## Файлы
- `bot.py` — хендлеры команд и сообщений (/start, /today, /history, /weight, /report, /settings), callback-кнопки
- `claude_client.py` — `analyze_food()`: запрос к LLM, ответ строго в JSON
- `db.py` — таблицы meals, weights, known_users; вся работа с БД
- `keyboards.py` — инлайн-клавиатуры
- `calc.py` — расчёт дневной нормы калорий
- `reports.py` — отчёты за период
- `reminders.py` — ежедневные напоминания
- `state.py` — состояние диалога в памяти (теряется при перезапуске)
- `formatting.py` — форматирование текста
- `test_claude.py` — ручная проверка API

## Правила безопасности
- НИКОГДА не выводи, не коммить и не отправляй содержимое `.env`, токены и ключи.
- `calories.db` и бэкапы БД — не коммитить (там данные пользователей).

## План работы (по порядку)
1. **Git и GitHub.** Проверить `.gitignore`, создать `requirements.txt`, сделать `git init` и первый коммит, выложить в публичный репозиторий на GitHub. Перед пушем убедиться, что `.env` и `*.db` не попали в коммит.
2. **README.md.** Что умеет бот, скриншоты, как запустить локально, ссылка на бота.
3. **Подключить Gonka API (gonka-api.org).** Сначала изучить их документацию. Сделать выбор провайдера через переменную в `.env` (`LLM_PROVIDER=anthropic|gonka`), чтобы можно было переключаться без правки кода. Сравнить качество разбора еды и скорость на 10 одинаковых запросах.
4. **Надёжность.** Обработка ошибок API (таймаут, неверный JSON) с понятным сообщением пользователю; логирование в файл.
5. **Деплой 24/7.** Выбрать хостинг, где бот работает без моего компьютера; вынести секреты в переменные окружения хостинга.
